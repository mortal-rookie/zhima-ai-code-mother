# 峙码前端重设计

基于原有 Vue 3、Vite、Ant Design Vue、Pinia 和 Vue Router 实现。后端业务代码未改动。设计以用户提供的四屏图片为参考，采用暖白、墨蓝、雾蓝、中文衬线标题和玻璃面板。

## 启动

需要兼容 Vite 7 的 Node.js（20.19+ 或 22.12+）。在此目录运行：

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 5173
```

默认仍使用仓库原有环境配置。可通过 `.env.development.local` 设置本地后端：

```dotenv
VITE_API_BASE_URL=http://localhost:8123/api
VITE_DEPLOY_DOMAIN=http://localhost:8123/api/deploy
```

部署地址须与实际后端的 `code.deploy-host` 配置匹配。前端请求携带 Cookie；跨域部署需要后端允许对应来源和凭证。没有启动后端时，首页和模板仍可访问，应用列表显示重试提示，不会伪造业务数据。

## 页面

| 路径 | 功能 |
| --- | --- |
| /welcome | 品牌首页 |
| / | 创作工作台，真实应用列表 |
| /templates | 8 个需求模板、关键词搜索与分类 |
| /app/new | 需求编辑、风格选择、调用真实创建接口 |
| /resources | 使用指南与开源代码入口 |
| /my/apps | 保留原有搜索、预览、详情、重命名与删除 |
| /app/chat/:id | 保留流式生成、历史对话、可视化修改、部署和下载 |
| /user/*、/admin/* | 保留资料、账户、协议和管理功能 |

模板填入可编辑的 `initPrompt`，风格描述也写入该字段，不新增后端不支持的参数。没有设计导入、数据库连接、支付订阅或模板克隆接口，所以没有虚构这些功能。

登录前的需求和风格保存在当前标签页的 sessionStorage 中，按模板隔离；登录后返回原页面。公开应用不请求私有对话历史；管理员入口按角色显示。每日额度依据原有前后端规则：普通用户 2 次，继续对话也计次。

## 动态交互

首页问候区加入可莉互动动画：待机眨眼与轻晃，悬停／聚焦挥手，点击跳跃、星星和鼓励气泡。可隐藏并重新召唤，选择保存在 localStorage；手机缩小角色并避开输入区域。精灵图由内置 image_gen 生成并随项目保存，资源说明与完整提示词见 `src/assets/klee/README.md`。

侧边栏顶部提供收起／展开按钮：桌面收起至 80px 图标导航，手机收起导航行；主内容区同步调整，状态保存在 localStorage。支持键盘操作和导航名称提示，登录／注册卡片在折叠后仍居中。

- 背景波浪、光晕和玻璃面板缓慢漂浮，鼠标移动带动前后景视差。
- 桌面卡片随鼠标轻微倾斜、抬升，光感跟随指针；模板插画和箭头独立响应悬停。
- 按钮、导航、卡片支持点击光波与按压反馈，键盘操作也有反馈。
- 滚动时模块错落显现，异步加载的应用列表同样支持；模板筛选平滑重排，页面进入和退出柔和过渡。
- 输入框聚焦呈现光感，创建请求期间显示呼吸反馈；使用指南平滑展开和收起。

无额外动画依赖。鼠标视差仅在移动时运行动画帧，场景离开视口或标签页隐藏时暂停背景动画；遵循系统「减少动态效果」设置，触屏使用按压反馈。

## 校验

```sh
npm run build
```

已完成类型检查与生产构建；浏览器检查涵盖模板搜索与选择、需求预填、登录引导、草稿及风格恢复、390px 移动布局。真实登录成功、AI 生成、COS 上传和部署还需要运行后端及其依赖进行联调。

动态版本另检查了背景动画运行及变换、指针视差、滚动后模块显现、模板分类与空结果、指南展开收起、390px 页面无横向溢出及输入按钮位置。动态效果应通过本地预览体验，静态截图只展示布局。

可莉版本检查了精灵图透明通道、动画帧切换、点击星星与气泡、隐藏后刷新及重新召唤、390px 布局、离开视口暂停和路由卸载。
